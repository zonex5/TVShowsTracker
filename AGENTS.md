# TVShowsTracker

Локальный Windows-дневник просмотра сериалов с русскоязычным интерфейсом. При каждом изменении приложения обновляйте соответствующие разделы этого файла в том же наборе правок. Описывайте видимые действия, правила работы, хранение данных и ограничения, которые понадобятся для воссоздания текущей версии. Запланированные функции держите отдельно.

## Проект и сборка

- WPF, .NET Framework 4.8, C# 7.3. SDK-проект TVShowsTracker.csproj с типом WinExe со ссылками на System.Net.Http и System.Runtime.Serialization и пакетом LiteDB 5.0.21. Для сборки нужен .NET Framework 4.8 Developer Pack.
- Из корня выполнить `msbuild TVShowsTracker.csproj /restore /p:Configuration=Release`. Исполняемый файл находится в `bin\Release\net48\TVShowsTracker.exe`.
- App.xaml запускает MainWindow. MainWindow.xaml задаёт представление и стили, MainWindow.xaml.cs обрабатывает действия. AddSeriesWindow.xaml и AddSeriesWindow.xaml.cs задают диалог добавления. Theme.xaml содержит общие стили. App.ico содержит иконку приложения и окон в нескольких размерах. Library.cs содержит модели, клиент TVmaze и локальное хранилище.

## Интерфейс

- Окно «TVShowsTracker · Дневник просмотра» открывается по центру экрана. Начальный размер 1120 × 760, минимальный 830 × 540. Шрифт Segoe UI. Интерфейс использует светлую тему. Фон #F3F5FA, панели #FFFFFF со скруглением, основной текст #20283A, вторичный #526078, акцент прогресса #6748CE.
- Справа от надписи «МОЯ БИБЛИОТЕКА» расположены три кнопки 26 × 26 с подсказками. Плюс «Добавить сериал» открывает модальное окно «Добавить сериал» по центру главного окна и переводит фокус в поле ввода. Между плюсом и стрелкой обновления находится кнопка «Импортировать из текстового файла». Стрелка «Обновить каталог» запускает обновление. Поиск запускается клавишей Enter или щелчком по лупе справа внутри поля ввода. Результаты показывают миниатюры постеров 34 × 48 с заглушкой ▧, названия и годы премьеры. Первый результат выбран. Двойной щелчок по результату или Enter в списке добавляет сериал и закрывает диалог. Ошибки отображаются в диалоге. Диалог закрывается крестиком в заголовке или клавишей Escape. Максимальная высота списка результатов 260. Во время загрузки и сохранения добавляемого сериала диалог остаётся открытым.
- Слева панель «МОЯ БИБЛИОТЕКА» шириной 330. Сериалы сортируются по последнему изменению прогресса. Изменение отметки серии, отметка сезона или смена текущей серии поднимает сериал в начало после сохранения. Записи без сохранённого порядка активности сортируются по названию. Обновление каталога порядок активности не меняет. В каждой строке слева миниатюра постера 34 × 48 с заглушкой ▧, справа переносимое название с годом премьеры в скобках, если год известен. Фиолетовая точка справа появляется, если сериал не на паузе и в загруженном каталоге есть хотя бы одна непросмотренная серия. При наведении видна подсказка «Есть непросмотренные серии». У сериала на паузе справа от названия виден значок с двумя полосками и подсказкой «На паузе».
- Внизу библиотеки четыре вкладки в один ряд с общей нижней линией. Активная вкладка выделена светло-фиолетовым фоном и фиолетовой линией снизу, при наведении фон меняется, клавиатурный фокус отмечен фиолетовой рамкой. «Все» открывается по умолчанию. «Непросмотренные» показывает сериалы с непросмотренными сериями из каталога. «Завершённые» показывает сериалы со статусом TVmaze Ended независимо от прогресса. Сериалы, поставленные на паузу вручную, отображаются только во вкладках «Все» и «На паузе». Для старых записей статус появляется после успешного обновления каталога.
- Справа карточка выбранного сериала. Сверху постер в области 88 × 126 с заглушкой «Постер», название, количество просмотренных серий из общего числа, число сезонов, полоса прогресса, текущая или следующая серия и ссылка «Карточка на TVmaze». Если сериал не выбран, вместо карточки отображается «Найдите сериал и добавьте его в библиотеку».
- Под карточкой заголовка расположены выбор сезона и кнопка «Отметить сезон». Ниже список серий с флажком просмотра. При наведении на строку справа появляется компактная кнопка с треугольником и подсказкой «Смотрю». Когда курсор уходит со строки, кнопка скрывается без смещения содержимого. Кнопка удаления расположена только в контекстном меню библиотеки.
- Внизу строка состояния для поиска, загрузки, сохранения и ошибок, справа ссылка «Данные TVmaze · CC BY-SA».

## Действия и правила просмотра

- Добавление загружает карточку, сезоны и серии, сохраняет сериал и открывает его карточку. Повторное добавление открывает существующую запись. Дубликаты определяются по ID TVmaze.
- Сезоны отсортированы по номеру. Подпись показывает число серий в каталоге, а при большем заявленном количестве показывает «N из M». Серии отсортированы по номеру в сезоне.
- Строка серии показывает номер, название и «Выход ДД.ММ.ГГГГ», если TVmaze передал корректную дату. Даты видны для вышедших и будущих серий. Выбранная текущая серия дополнительно помечается «◂ смотрю».
- «Смотрю» сохраняет текущую серию. Флажок добавляет или снимает отметку просмотра. Отметка текущей серии как просмотренной очищает текущий выбор. Без явного выбора карточка показывает первую непросмотренную серию и открывает её сезон. Прогресс рассчитывается по сериям из загруженного каталога.
- В карточке сериала «Поставить на паузу» добавляет его во вкладку «На паузе». «Снять с паузы» убирает его оттуда. Те же команды доступны в контекстном меню строки и действуют на сериал под курсором. Постановка на паузу отключена в обоих местах, если статус TVmaze — Ended и в непустом каталоге просмотрены все серии. Снятие с паузы остаётся доступным. Действия сохраняют отметки просмотра, текущую серию и порядок активности.
- «Отметить сезон» отмечает все серии выбранного сезона и отключена, если в сезоне нет непросмотренных серий. Если текущая серия оказалась среди просмотренных, текущий выбор очищается.
- Правый клик по строке сериала открывает контекстное меню. «Отметить сезон как просмотренный» раскрывает список сезонов с сериями. Сезоны, просмотренные полностью, отключены. Команда действует на сериал под курсором даже при открытой карточке другого сериала.
- «Удалить сериал из списка…» доступно через то же меню. Диалог предупреждает об удалении сериала вместе с отметками просмотра, предлагает «Да» и «Нет», по умолчанию выбрано «Нет». Удаление сохраняется после подтверждения.

## Импорт из текстового файла

- Кнопка импорта открывает диалог выбора файла. Используйте UTF-8 и одну запись на строку. Пустые строки игнорируются. В конце строки укажите сезон или сезон и серию через точку, отделив их от названия пробелом.
- «Название 2» отмечает все серии первого и второго сезонов. «Название 2.3» отмечает первый сезон целиком и первые три серии второго включительно.
- Импорт объединяет результаты поиска TVmaze и точные совпадения из библиотеки, убирая повторы по ID. Единственное точное совпадение названия без учёта регистра выбирается автоматически. При нескольких точных совпадениях, приблизительных результатах или пустой выдаче открывается окно выбора с исходной строкой, полем повторного поиска, названиями, годами и постерами. Можно изменить запрос, выбрать результат двойным щелчком или Enter либо пропустить строку кнопкой, крестиком или Escape. Выбор применяется только к текущей строке. Существующие записи переиспользуются по ID TVmaze. Сериал добавляется вместе с отметками. Прежние отметки и пауза сохраняются. Если текущая серия уже отмечена просмотренной, текущий выбор очищается. Изменение прогресса обновляет порядок активности.
- Успешные строки сохраняются отдельно в обычном хранилище. Ручной пропуск, неверный формат, отсутствие указанного сезона либо серии, сбой запроса и ошибка записи отражаются в отчёте. В конце отображается число обработанных и пропущенных строк, а при пропусках открывается отчёт. Импорт и обновление каталога выполняются по очереди. Во время импорта ручное добавление отключено.

## Источник данных и обновление

- Публичный API TVmaze использует HTTPS. Поиск выполняется через `/search/shows?q=...`. Для каждой записи загружаются `/shows/{id}`, `/shows/{id}/seasons` и `/shows/{id}/episodes`. Названия берутся из источника. Спецвыпуски исключаются по умолчанию API. Постеры загружаются по ссылке `image.medium`. Локальное хранилище содержит ссылки на изображения.
- При запуске приложение читает библиотеку и сразу показывает сохранённые записи, затем обновляет метаданные в фоне. Ручное обновление запускает тот же процесс. Записи обновляются последовательно. Сбой запроса оставляет сохранённые данные соответствующего сериала. ID просмотренных серий и текущая серия сохраняются при обновлении.
- Тайм-аут HTTP-запроса 15 секунд. При HTTP 429 клиент ждёт 10 секунд и повторяет запрос один раз.

## Локальное хранилище

- Движок LiteDB 5.0.21, собственный бинарный формат LiteDB v5. Путь вычисляется через `Environment.GetFolderPath(Environment.SpecialFolder.MyDocuments)` с добавлением `SeriesDesk\library.db`. Прежнее имя каталога сохранено для совместимости с существующей библиотекой. Так учитывается перенаправление системной папки «Документы». Отсутствующий файл означает пустую библиотеку.
- Один экземпляр приложения в сеансе Windows защищён именованным мьютексом `Local\SeriesDesk.Library`, имя которого сохранено для совместимости с прежней версией. База открывается через `new LiteDatabase(new ConnectionString { Filename = path }, mapper)` с настройками подключения по умолчанию.
- Коллекция `entries` хранит один BSON-документ на сериал. Имена ниже указаны в том виде, в котором они записаны на диске.

| Поле | BSON-тип | Содержимое |
| --- | --- | --- |
| `_id` | Int32 | ID сериала TVmaze, совпадает с `Show._id`. |
| `Show` | Document | `_id` (Int32), `name`, `premiered`, `status`, `url` (String), `image` (Document с полем `medium` типа String). `premiered` хранится строкой даты, обычно `YYYY-MM-DD`. `status` хранит строку TVmaze, например `Ended`. |
| `Seasons` | Array of Document | `number` (Int32), необязательное `episodeOrder` (Int32). |
| `Episodes` | Array of Document | `_id` (Int32, ID серии TVmaze), `season` (Int32), необязательное `number` (Int32), `name` и `airdate` (String). `airdate` хранится строкой даты, обычно `YYYY-MM-DD`. |
| `Watched` | Array of Int32 | Набор ID просмотренных серий. Порядок элементов не имеет значения. |
| `Current` | Int32, Null или отсутствует | ID явно выбранной текущей серии. При отсутствии поля текущая серия не задана. |
| `ActivityOrder` | Int64 | Порядковый номер последнего изменения прогресса. При отсутствии поля используется 0. |
| `IsPaused` | Boolean | Признак ручной паузы. При отсутствии поля используется false. |

- При использовании `BsonMapper` сохранять стандартные имена полей и стандартное преобразование свойства `id` в `_id` во вложенных моделях Show и Episode. Корневой `_id` задаётся явно из `Show.id` после `mapper.ToDocument(entry)`. В ответах TVmaze эти же идентификаторы называются `id`.
- У маппера `TrimWhitespace = false` и `EmptyStringToNull = false`. Стандартный маппер может опускать поля со значением null. Читатель принимает отсутствующие и явно заданные null для необязательных строк, `image`, `episodeOrder`, `number` серии и `Current`. Отсутствующие массивы `Seasons`, `Episodes` и `Watched` читаются как пустые коллекции. Старые записи без `Show.status` получают статус при успешном обновлении каталога.
- Во вложенном `Show` может быть строковое поле `Label`, которое текущий маппер записывает из вычисляемого свойства. При чтении подпись вычисляется заново из названия и года премьеры. `HasUnwatchedEpisodes` и `ShowUnwatchedIndicator` вычисляются из записи и исключены из BSON.
- Текущий код читает документы через `mapper.ToObject<Entry>(document)`. При сохранении удаляет содержимое `entries` и записывает актуальный список в одной транзакции с явными `_id`. При ошибке записи транзакция и изменение в интерфейсе откатываются. При ошибке чтения поиск и обновление отключаются, причина появляется в строке состояния.
- Обновление каталога заменяет `Show`, `Seasons` и `Episodes`, сохраняя `Watched`, `Current`, `ActivityOrder` и `IsPaused`. Сохранять ID просмотренных и текущей серии даже при их отсутствии в обновлённом каталоге. Формат поддерживает чтение старых записей по значениям по умолчанию без отдельной миграции.
