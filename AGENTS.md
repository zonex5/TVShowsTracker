# TVShowsTracker

Локальный Windows-дневник просмотра сериалов с русскоязычным интерфейсом. При каждом изменении приложения обновляйте соответствующие разделы этого файла в том же наборе правок. Описывайте видимые действия, правила работы, хранение данных и ограничения, которые понадобятся для воссоздания текущей версии. Запланированные функции держите отдельно.

## Проект и сборка

- WPF, .NET Framework 4.8, C# 7.3. SDK-проект TVShowsTracker.csproj с типом WinExe со ссылками на System.Net.Http и System.Runtime.Serialization и пакетом LiteDB 5.0.21. Для сборки нужен .NET Framework 4.8 Developer Pack.
- Из корня выполнить `msbuild TVShowsTracker.csproj /restore /p:Configuration=Release`. Исполняемый файл находится в `bin\Release\net48\TVShowsTracker.exe`.
- В JetBrains Rider открыть `TVShowsTracker.csproj`, выбрать конфигурацию `TVShowsTracker` и нажать Run или Debug. Общая конфигурация хранится в `.run/TVShowsTracker.run.xml` и собирает проект перед запуском.
- App.xaml запускает MainWindow. MainWindow.xaml задаёт представление и стили, MainWindow.xaml.cs обрабатывает действия. AddSeriesWindow.xaml и AddSeriesWindow.xaml.cs задают диалоги поиска и выбора при импорте. NoticeWindow.xaml и NoticeWindow.xaml.cs задают общие служебные диалоги. SettingsWindow.xaml и SettingsWindow.xaml.cs задают диалог настроек, AppSettings.cs хранит настройки в реестре. Theme.xaml содержит палитру и общие стили, подключённые через App.xaml. App.ico содержит иконку приложения и окон в нескольких размерах. Library.cs содержит модели, клиент TVmaze и локальное хранилище.

## Интерфейс

- Синяя рамка фокуса на кнопках появляется при навигации с клавиатуры. Щелчок мышью не оставляет рамку на кнопке.
- Окно «TVShowsTracker · Дневник просмотра» открывается по центру экрана. Начальный размер 1120 × 760, минимальный 830 × 540. Шрифт Segoe UI. Светлая тема использует фон #EDF1F6, белые панели со скруглениями, основной текст #17253A, вторичный #54657D и синие акценты. Заголовки окон и окно выбора файла предоставляются Windows.
- В верхней полосе слева значок приложения и заголовок «Дневник просмотра». Справа кнопки с подсказками «Импортировать из текстового файла», «Обновить каталог» и «Настройки», затем синяя кнопка «Добавить сериал». Во время обновления стрелку заменяет квадрат «Остановить обновление каталога».
- Шестерёнка «Настройки» открывает по центру главного окна светлый модальный диалог со скруглёнными углами и заголовком «Настройки» рядом с крестиком. Под заголовком один переключатель «Обновлять каталог при запуске». Значение сохраняется сразу и применяется при следующем запуске. При ошибке записи переключатель возвращается в предыдущее положение, а причина отображается в диалоге. Диалог закрывается крестиком или клавишей Escape.
- «Добавить сериал» открывает модальный диалог по центру главного окна и переводит фокус в поле ввода. Поиск запускается клавишей Enter или щелчком по лупе внутри поля. Результаты показывают миниатюры постеров 34 × 48 со значком-заглушкой, названия и годы премьеры. Первый результат выбран. Двойной щелчок по результату или Enter в списке добавляет сериал и закрывает диалог. Ошибки отображаются в диалоге. Диалог закрывается крестиком или клавишей Escape. Максимальная высота списка результатов 260. Во время загрузки и сохранения добавляемого сериала диалог остаётся открытым.
- Слева белая карточка «Моя библиотека» шириной 320. Сериалы сортируются по последнему изменению прогресса. Изменение отметки серии, отметка сезона или смена текущей серии поднимает сериал в начало после сохранения. Записи без сохранённого порядка активности сортируются по названию. Обновление каталога порядок активности не меняет. В каждой скруглённой строке слева миниатюра постера 34 × 48 со значком-заглушкой, справа переносимое название с годом премьеры, если он известен. Синяя точка с подсказкой «Есть непросмотренные серии» появляется, если сериал не на паузе и в загруженном каталоге есть хотя бы одна непросмотренная серия. У сериала на паузе в правом верхнем углу строки виден светло-янтарный бейдж «На паузе».
- Вверху библиотеки четыре вкладки в одной скруглённой полосе. Активная вкладка выделена голубой плашкой, клавиатурный фокус отмечен синей рамкой. «Все» открывается по умолчанию. «Непросмотренные» показывает сериалы с непросмотренными сериями из каталога. «Завершённые» показывает сериалы со статусом TVmaze Ended независимо от прогресса. Сериалы, поставленные на паузу вручную, отображаются только во вкладках «Все» и «На паузе». Для старых записей статус появляется после успешного обновления каталога. Если в разделе нет сериалов, на карточке библиотеки появляется соответствующая подпись.
- Кнопка с лупой справа от заголовка «Моя библиотека» показывает поле поиска над вкладками и переводит в него фокус. При запуске поле скрыто. Повторное нажатие на лупу или клавиша Escape скрывают поле, сбрасывают запрос и возвращают фокус на лупу. Поле фильтрует сохранённые сериалы активной вкладки по части основного или русского названия сразу при вводе. Регистр и пробелы по краям запроса игнорируются. Запрос сохраняется при переключении вкладок, а крестик внутри поля очищает запрос и оставляет поле открытым. Если совпадений нет, список показывает «Сериалы не найдены». Порядок сортировки сохраняется. Если выбранный сериал остаётся в результатах, его карточка и выбранный сезон остаются открытыми. Добавление через TVmaze открывает карточку добавленного или уже сохранённого сериала и при необходимости сбрасывает поиск и переключается на «Все».
- Справа от заголовка «Моя библиотека» мелким серым шрифтом отображается количество сериалов в списке активной вкладки с учётом поиска.
- В строке библиотеки доступное русское название отображается более мелким шрифтом под основным названием с годом. В карточке прогресса оно идёт справа от основного названия в общем заголовке. При нехватке ширины текст переносится.
- Справа две отдельные карточки. В карточке прогресса видны постер в области 80 × 114 со значком и заглушкой «Постер», название, количество просмотренных серий из общего числа, число сезонов, синяя полоса прогресса, текущая или следующая серия и ссылка «Карточка на TVmaze». Если сериал не выбран, карточки заменяет панель «Сериал не выбран» с подсказкой.
- Карточка «Серии» содержит выбор сезона, команды «Отметить сезон» и «Поставить на паузу» или «Снять с паузы», а также список скруглённых строк с флажками просмотра. Кнопка с треугольником и подсказкой «Смотрю» появляется при наведении или клавиатурном фокусе внутри строки. Место под кнопку зарезервировано. Контекстное меню и подменю сезонов оформлены как белые панели с голубым выделением, команда удаления показана красным.
- Скруглённая строка состояния внизу видна только во время обновления каталога. После завершения или остановки строка скрывается, а результат доступен в подсказке кнопки обновления. Диалоги ошибок, отчёта об импорте, подтверждения удаления и сообщения о повторном запуске используют общую тему.

## Действия и правила просмотра

- Добавление загружает карточку, сезоны и серии, сохраняет сериал и открывает его карточку. Повторное добавление открывает существующую запись. Дубликаты определяются по ID TVmaze.
- Сезоны отсортированы по номеру. Подпись показывает число серий в каталоге, а при большем заявленном количестве показывает «N из M». Серии отсортированы по номеру в сезоне.
- Строка серии показывает номер, название и «Выход ДД.ММ.ГГГГ», если TVmaze передал корректную дату. Даты видны для вышедших и будущих серий. Выбранная текущая серия дополнительно помечается «◂ смотрю».
- «Смотрю» сохраняет текущую серию. Флажок добавляет или снимает отметку просмотра. Отметка текущей серии как просмотренной очищает текущий выбор. Без явного выбора карточка показывает первую непросмотренную серию и открывает её сезон. Прогресс рассчитывается по сериям из загруженного каталога.
- В карточке сериала «Поставить на паузу» добавляет его во вкладку «На паузе». «Снять с паузы» убирает его оттуда. Те же команды доступны в контекстном меню строки и действуют на сериал под курсором. Постановка на паузу отключена в обоих местах, если статус TVmaze — Ended и в непустом каталоге просмотрены все серии. Снятие с паузы остаётся доступным. Действия сохраняют отметки просмотра, текущую серию и порядок активности.
- «Отметить сезон» отмечает все серии выбранного сезона и отключена, если в сезоне нет непросмотренных серий. Если текущая серия оказалась среди просмотренных, текущий выбор очищается.
- Правый клик по строке сериала открывает контекстное меню. «Отметить сезон как просмотренный» раскрывает список сезонов с сериями. Сезоны, просмотренные полностью, отключены. Команда действует на сериал под курсором даже при открытой карточке другого сериала.
- «Удалить сериал из списка…» доступно через то же меню. Диалог предупреждает об удалении сериала вместе с отметками просмотра, предлагает «Да, удалить» и «Нет», по умолчанию выбрано «Нет». Удаление сохраняется после подтверждения.

## Импорт из текстового файла

- Кнопка импорта открывает диалог выбора файла. Используйте UTF-8 и одну запись на строку. Пустые строки игнорируются. В конце строки укажите сезон или сезон и серию через точку, отделив их от названия пробелом.
- «Название 2» отмечает все серии первого и второго сезонов. «Название 2.3» отмечает первый сезон целиком и первые три серии второго включительно.
- Импорт объединяет результаты поиска TVmaze и точные совпадения из библиотеки, убирая повторы по ID. Единственное точное совпадение названия без учёта регистра выбирается автоматически. При нескольких точных совпадениях, приблизительных результатах или пустой выдаче открывается окно выбора с исходной строкой, полем повторного поиска, названиями, годами и постерами. Можно изменить запрос, выбрать результат двойным щелчком или Enter либо пропустить строку кнопкой, крестиком или Escape. Выбор применяется только к текущей строке. Существующие записи переиспользуются по ID TVmaze. Сериал добавляется вместе с отметками. Прежние отметки и пауза сохраняются. Если текущая серия уже отмечена просмотренной, текущий выбор очищается. Изменение прогресса обновляет порядок активности.
- Успешные строки сохраняются отдельно в обычном хранилище. Ручной пропуск, неверный формат, отсутствие указанного сезона либо серии, сбой запроса и ошибка записи отражаются в отчёте. Подсказка кнопки импорта показывает текущую строку. В конце диалог показывает число обработанных и пропущенных строк и причины пропусков, если они были. После выбора файла приложение останавливает текущее обновление каталога и запускает импорт. Во время импорта ручное добавление и обновление отключены.

## Источник данных и обновление

- Публичный API TVmaze использует HTTPS. Поиск выполняется через `/search/shows?q=...`. Для каждой записи загружаются `/shows/{id}?embed=akas`, `/shows/{id}/seasons` и `/shows/{id}/episodes`. Основное название берётся из поля `name`. Для русской строки используется первый вариант из `_embedded.akas` с русскими буквами и кодом страны `RU`. Совпадение с основным названием без учёта регистра и русскоязычный сериал с основным названием на кириллице оставляют только основное название. Русские названия загружаются при добавлении, импорте новых записей и обновлении каталога. Если в ответе нет списка вариантов, используется ранее сохранённое русское название, когда оно подходит под те же правила отображения. Спецвыпуски исключаются по умолчанию API. Постеры загружаются по ссылке `image.medium`. Локальное хранилище содержит ссылки на изображения.
- При запуске приложение читает библиотеку и сразу показывает сохранённые записи. Если включена настройка «Обновлять каталог при запуске», приложение затем обновляет метаданные в фоне. Ручное обновление доступно при любом значении настройки. Записи обновляются последовательно, строка состояния показывает текущую позицию и общий размер очереди. Во время обновления можно открыть добавление и импорт. Обновление можно остановить той же кнопкой, которая его запускает. Ошибка отдельной записи оставляет её сохранённые данные, после чего обновляется следующая запись. При ошибке подключения, тайм-ауте, HTTP 5xx или повторном HTTP 429 текущий проход останавливается, а локальная библиотека остаётся доступной. Уже сохранённые обновления сохраняются при остановке. ID просмотренных серий и текущая серия сохраняются при обновлении.
- Тайм-аут HTTP-запроса 15 секунд. При HTTP 429 клиент ждёт 10 секунд и повторяет запрос один раз.

## Локальное хранилище

- Настройки хранятся для текущего пользователя Windows в разделе реестра `HKEY_CURRENT_USER\Software\TVShowsTracker`. Параметр `RefreshCatalogOnStartup` имеет тип `REG_DWORD`. `0` отключает автоматическое обновление, `1` включает. При отсутствии параметра обновление включено. При ошибке чтения приложение показывает причину и оставляет каталог доступным для ручного обновления.
- Движок LiteDB 5.0.21, собственный бинарный формат LiteDB v5. Путь вычисляется через `Environment.GetFolderPath(Environment.SpecialFolder.MyDocuments)` с добавлением `TVShowsTracker\library.db`. Так учитывается перенаправление системной папки «Документы». Отсутствующий файл означает пустую библиотеку.
- Один экземпляр приложения в сеансе Windows защищён именованным мьютексом `Local\TVShowsTracker.Library`. База открывается через `new LiteDatabase(new ConnectionString { Filename = path }, mapper)` с настройками подключения по умолчанию.
- Коллекция `entries` хранит один BSON-документ на сериал. Имена ниже указаны в том виде, в котором они записаны на диске.

| Поле | BSON-тип | Содержимое |
| --- | --- | --- |
| `_id` | Int32 | ID сериала TVmaze, совпадает с `Show._id`. |
| `Show` | Document | `_id` (Int32), `name`, `premiered`, `status`, `url` (String), `image` (Document с полем `medium` типа String), необязательное `RussianTitle` (String). `premiered` хранится строкой даты, обычно `YYYY-MM-DD`. `status` хранит строку TVmaze, например `Ended`. |
| `Seasons` | Array of Document | `number` (Int32), необязательное `episodeOrder` (Int32). |
| `Episodes` | Array of Document | `_id` (Int32, ID серии TVmaze), `season` (Int32), необязательное `number` (Int32), `name` и `airdate` (String). `airdate` хранится строкой даты, обычно `YYYY-MM-DD`. |
| `Watched` | Array of Int32 | Набор ID просмотренных серий. Порядок элементов не имеет значения. |
| `Current` | Int32, Null или отсутствует | ID явно выбранной текущей серии. При отсутствии поля текущая серия не задана. |
| `ActivityOrder` | Int64 | Порядковый номер последнего изменения прогресса. При отсутствии поля используется 0. |
| `IsPaused` | Boolean | Признак ручной паузы. При отсутствии поля используется false. |

- При использовании `BsonMapper` сохранять стандартные имена полей и стандартное преобразование свойства `id` в `_id` во вложенных моделях Show и Episode. Корневой `_id` задаётся явно из `Show.id` после `mapper.ToDocument(entry)`. В ответах TVmaze эти же идентификаторы называются `id`.
- У маппера `TrimWhitespace = false` и `EmptyStringToNull = false`. Стандартный маппер может опускать поля со значением null. Читатель принимает отсутствующие и явно заданные null для необязательных строк, `image`, `episodeOrder`, `number` серии и `Current`. Отсутствующие массивы `Seasons`, `Episodes` и `Watched` читаются как пустые коллекции. Старые записи без `Show.status` получают статус при успешном обновлении каталога.
- Во вложенном `Show` может быть строковое поле `Label`, которое текущий маппер записывает из вычисляемого свойства. При чтении подпись вычисляется заново из названия и года премьеры. Для русской строки сохраняется только выбранное `RussianTitle`. Поля ответа `language` и `_embedded` и вычисляемые свойства `HasRussianTitle`, `HasUnwatchedEpisodes` и `ShowUnwatchedIndicator` исключены из BSON. Записи без `RussianTitle` получают его при обновлении каталога, если у TVmaze есть подходящий вариант.
- Текущий код читает документы через `mapper.ToObject<Entry>(document)`. При сохранении удаляет содержимое `entries` и записывает актуальный список в одной транзакции с явными `_id`. При ошибке записи транзакция и изменение в интерфейсе откатываются. При ошибке чтения поиск и обновление отключаются, причина отображается в диалоге.
- Обновление каталога заменяет `Show`, `Seasons` и `Episodes`, сохраняя `Watched`, `Current`, `ActivityOrder` и `IsPaused`. Сохранять ID просмотренных и текущей серии даже при их отсутствии в обновлённом каталоге. Формат поддерживает чтение старых записей по значениям по умолчанию без отдельной миграции.
